# OctoAcme — Project Intake Checklist

## Purpose
Provide a consistent, repeatable process for evaluating and onboarding new work requests before they enter the planning phase. Completing this checklist ensures that every initiative starts with a shared understanding of scope, value, and ownership.

## When to use
Use this checklist for any new project proposal, feature request, or significant piece of work before kicking off formal planning.

---

## Step 1 — Request Intake

- [ ] Request submitted via the agreed intake channel (e.g., issue template, intake form, or direct PM contact)
- [ ] Requestor identified and reachable for clarification
- [ ] Requested-by date and desired-completion date noted
- [ ] Request categorized: `New Feature` / `Enhancement` / `Bug Fix` / `Tech Debt` / `Compliance` / `Other`

---

## Step 2 — Problem & Value Alignment

- [ ] Problem statement written in plain language (1–3 sentences)
- [ ] Business or user value articulated (why now, why this?)
- [ ] Success metrics defined (how will we know it's done and working?)
- [ ] Connection to product roadmap or OKR confirmed (or explicitly marked as unplanned)
- [ ] Sponsor / champion identified and confirmed as available

---

## Step 3 — Stakeholder Identification

- [ ] Primary stakeholder(s) named
- [ ] Approver(s) for go/no-go decision named
- [ ] Downstream teams or systems affected identified
- [ ] External dependencies (third-party, legal, security, etc.) noted

---

## Step 4 — Scope & Effort Pre-Assessment

- [ ] Initial scope boundary described (what's in, what's out)
- [ ] High-level effort estimate provided (rough T-shirt sizing: XS / S / M / L / XL)
- [ ] Known constraints (budget, timeline, resource limits) documented
- [ ] Potential risks or blockers noted at a high level

---

## Step 5 — Resourcing Check

- [ ] Team or individuals available to own the work confirmed
- [ ] Any skill gaps or external help needed identified
- [ ] If work spans multiple teams, coordination lead assigned

---

## Step 6 — Go / No-Go Decision

- [ ] Intake checklist reviewed in PM/PdM sync or equivalent forum
- [ ] Decision recorded: `Approved` / `Deferred` / `Rejected` (with reason)
- [ ] Decision log entry created (see [Decision Log Template](octoacme-decision-log-template.md))
- [ ] Requestor notified of decision and rationale

---

## Step 7 — Handoff to Planning

- [ ] Project One-pager created or linked (see [Project Initiation Guide](octoacme-project-initiation.md))
- [ ] Work item / epic created in the project board
- [ ] PM assigned and kickoff meeting scheduled
- [ ] Intake record archived or linked from the project board item
